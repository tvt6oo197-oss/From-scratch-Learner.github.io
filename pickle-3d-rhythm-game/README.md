# 피클 3D 리듬게임 · Pickle Rhythm

네온 하이웨이를 달리며 4개 레인에 떨어지는 노트를 치는 WebGL 3D 리듬게임입니다.
음악은 오디오 파일 없이 브라우저에서 실시간으로 합성되고, 화면과 채보도 같은 박자 정보로 만들어집니다.
파일 하나(`index.html`)로 동작하며 외부 라이브러리나 네트워크 요청이 없습니다.

## 플레이

https://tvt6oo197-oss.github.io/From-scratch-Learner.github.io/pickle-3d-rhythm-game/

휴대폰·PC 브라우저에서 바로 열립니다. 첫 소리는 시작 버튼을 누른 뒤에 나옵니다(브라우저 자동재생 정책).

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 1~4번 레인 | `D` `F` `J` `K` (또는 `←` `↓` `↑` `→`) | 화면 아래 4개 패드 |
| 일시정지 / 재개 | `Space` 또는 `Esc` | 상단 일시정지 버튼 |
| 다시 시작 | 일시정지 화면에서 `R` | 일시정지 화면의 다시 시작 |
| 곡 선택 | 제목 화면에서 `↑` `↓` | 곡 카드 |
| 난이도 | 제목 화면에서 `←` `→` 또는 `1` `2` `3` | EASY / NORMAL / HARD |
| 시작 / 결과에서 다시 | `Enter` 또는 `Space` | 시작 버튼 |

## 수록곡

| 곡 | BPM | 장르 |
| --- | --- | --- |
| 라일락 새벽 · Lilac Dawn | 104 | 몽환 신스팝 · F major |
| 피클 서킷 · Pickle Circuit | 128 | 에너제틱 하우스 · E minor |
| 사워 러시 · Sour Rush | 148 | 하드코어 신스 · D minor |

난이도는 EASY(Lv.3) / NORMAL(Lv.7) / HARD(Lv.12) 세 단계입니다.
